# Bản chép/tóm tắt bài báo

Các file trong thư mục này là **tài liệu tham khảo bên ngoài**. Giữ nguyên nội dung
đã lưu; chưa bảo đảm bản chép đầy đủ và chính xác từng công thức/bảng so với PDF.
Khi cần trích số hoặc công thức, kiểm tra [PDF gốc đang lưu](../papers/).

| Bản chép | Chủ đề |
| :-- | :-- |
| [iDCF](iDCF.md) | Identifiable latent confounders, iVAE và feedback model |
| [CDR](CDR.md) | Conservative doubly robust learning; nhiều biến thể DR+CDR |
| [IViDR](IViDR.md) | IV/treatment reconstruction và iVAE |
| [ReCRec](ReCRec.md) | Tài liệu nghiên cứu bổ sung, chưa thuộc bộ mô hình đang chạy |
| [LCDR](LCDR.md) | Bản tổng hợp từ PDF/LaTeX; công thức, số paper, phần paper không công bố |
| [ConAlign](ConAlign.md) | Bản tổng hợp từ PDF và source tác giả; khác biệt paper/source |

Ghi chú biên tập cũ trong bản chép CDR chỉ là dẫn đường lịch sử, không thay cho
[trạng thái triển khai](../CURRENT_STATE.md). Khác biệt paper/source/dự án được
ghi ở [đối chiếu mô hình](../benchmarks/paper_model_alignment.md), không sửa lại
nội dung bài báo để khớp code hoặc điểm của dự án.
